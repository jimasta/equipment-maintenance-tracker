# Equipment Maintenance Tracker

Sistema web para centralizar cadastro de ativos industriais, planos de manutenção preventiva e histórico de execução, com alertas de vencimento.

> README mínimo (Etapa 4 do SDLC). Versão completa com screenshots e instruções detalhadas na Etapa 7.

## Stack
- Backend: Node.js + Express + TypeScript + Prisma
- Frontend: React + TypeScript + Vite
- Banco de dados: PostgreSQL
- Containerização: Docker + docker-compose

## Rodando localmente

```bash
docker-compose up
```

- Backend: http://localhost:3000
- Frontend: http://localhost:5173
